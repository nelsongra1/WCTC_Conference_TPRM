# Don't Buy the Breach: WCTC TPRM Handouts

Prepared for the West Central Tech Conference.

Grant Nelson | Doosan Digital Innovation

## Contents

This repository includes the conference handout package for a third-party risk management session:

1. TPRM Lifecycle Checklist
2. Vendor Access and Offboarding Checklist
3. Governed Exception Record Template
4. Monitoring Context Questions
5. Final slide deck PDF

## Repository Layout

- `TPRM Templates/`
  - `01_TPRM_Lifecycle_Checklist.docx`
  - `02_Vendor_Access_and_Offboarding_Checklist.docx`
  - `03_Governed_Exception_Record_Template.docx`
  - `04_Monitoring_Context_Questions.docx`
- `Slide Deck/`
  - `05_Dont_Buy_the_Breach_Final_Slide_Deck.pdf`

## Format Notes

- The checklist and template files are provided as DOCX documents for local editing and reuse.
- The slide deck is provided as a PDF for viewing and distribution.

## Public Use Notice

All scenarios and guidance are generalized for public conference use. This package contains no company-specific vendor names, products, architectures, incidents, credentials, IP addresses, internal documents, or unreleased role information.
